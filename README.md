# 🏛️ SNK: The Museum of My First Website

> *Exhibit #1: A personal website built in 12th standard, right after learning HTML, CSS and JavaScript. No AI, no vibe coding. Just a video tutorial, pausing every 10 seconds, and pure stubbornness.* 

 **Live exhibit:** [shivanandu003.github.io](https://shivanandu003.github.io/)

---

## 🎟️ Welcome, Visitor

Please keep your voice down, don't touch the code, and **do not** open DevTools. What you see there cannot be unseen.

This repo is a **museum**. It preserves my very first personal website, made when I had just learnt HTML, CSS and JS. I watched a video as a reference and copied it line by line, rewinding every time my page looked nothing like the tutorial's.

Every bug in here was fixed by a real human brain (mine), powered by tea and panic.  No ChatGPT was harmed, or consulted.

- **HTML**: the walls (a bit crooked, but they stand)
- **CSS**: the paint (applied with great enthusiasm)

##  Why This Museum Exists

-  It's my first real website
-  I learned it from a video, back when "AI-assisted coding" meant asking a senior
-  It proves that HTML, CSS and JS are enough to build something you're proud of
-  It reminds me that I once thought saying hello in five languages was peak web design (honestly, it still is)

The code isn't perfect, but it's mine, and everything I've built since started in this building.
